# 📅 Расписание занятий МГЭИ им. А.Д. Сахарова БГУ

Современное PWA-приложение для просмотра расписания занятий. Восстановлено из бэкапа VDS
и адаптировано для **GitHub Pages** — без сервера, полностью статически.

**Данные берутся с официального сайта** `rsp.iseu.by`.

---

## ✨ Возможности

- 🔄 Автоматическое обновление данных с сайта расписания
- 📅 Просмотр расписания по дням (Пн–Сб) с вкладками
- ⬅️ ➡️ Навигация по неделям (текущая и будущие)
- 💾 Настройки группы сохраняются автоматически
- 📱 Устанавливается как приложение (PWA)
- 🌙 8 тем оформления, тёмный премиальный дизайн
- ⚡ Текущая пара подсвечивается с обратным отсчётом
- 🧪 Фильтр подгрупп для лабораторных работ

---

## 🏗 Как это работает

GitHub Pages отдаёт только статические файлы, а сайт расписания `rsp.iseu.by` не разрешает
прямые запросы из браузера (CORS). Поэтому:

```
GitHub Actions (расписание: ср/пт/сб/вс)          Пользователь
        │                                              │
        ▼                                              ▼
  node crawler.js ──► public/data/*.json ──► dist/ ──► GitHub Pages
  (обходит rsp.iseu.by:                                (статика, без сервера)
   факультеты, группы, 7 недель расписаний)
```

- `public/data/meta.json` — факультеты, формы обучения, группы, недели
- `public/data/parsed/{groupId}_{weekDate}.json` — распарсенное расписание
- Workflow `.github/workflows/crawl-and-deploy.yml` запускает краулер, коммитит свежие
  данные в репозиторий и деплоит сайт на Pages.

## 🖥️ Локальный запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

```bash
npm run build      # сборка в dist/
npm run preview    # локальный предпросмотр сборки
npm run crawl      # вручную обновить данные с rsp.iseu.by
npm test           # тесты
```
